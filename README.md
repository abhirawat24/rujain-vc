# rujain-vc
Developed a responsive static tourism website for a client focused on promoting Nainital tourism. Built using React.js, the website features an intuitive UI, WhatsApp integration for direct customer inquiries, email connectivity, and Google Maps integration for easy location discovery and navigation. Designed to provide visitors with a seamless experience while helping the client showcase tourism services and connect with potential customers.
