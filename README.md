
# Rujain Travels Nainital

A responsive cab booking website for Rujain Travels Nainital, Uttarakhand.

## Features

- Responsive design for mobile, tablet and desktop
- Vehicle listings and booking enquiries
- Popular destination information
- WhatsApp booking integration
- Direct calling and email contact options
- Animated sections and preloader
- Interactive destination details

## Tech Stack

- React.js
- Vite
- Tailwind CSS
- Framer Motion
- React Icons
- Swiper.js

## Run Locally

Clone the repository:

```bash
git clone https://github.com/abhirawat24/rujain-vc.git
```

Navigate into the project:

```bash
cd rujain-vc
```

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```

Create production build:

```bash
npm run build
```
